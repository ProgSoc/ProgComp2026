# ProgComp2026
Repository of custom question prompts and solutions in multiple languages for the 2026 ProgComp questions.

The verifiers for each question are sourced directly from either [DMOJ](https://dmoj.ca/) or [CSES](https://cses.fi/).
Each folder corresponds to one question, and the name is formatted such as `[Question Number]-[Source]-[Question ID]`.
With the provided question IDs, you can find the original question sources.
